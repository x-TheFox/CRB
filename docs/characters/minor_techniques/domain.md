# Minor Cursed Techniques — Domain Status & Anti-Domain Arts

## 1. Domain Status
- **Innate Domain Expansion**: None of the 4 minor techniques possess an innate domain expansion in canon or in JJA.
- **Anti-Domain Arts**:
  - **Simple Domain**: Available as an unlockable skill via the progression system for Charles Bernard and general auxiliary sorcerers.
  - **Miracle Domain Bypass**: Haruta's miracles can survive a single domain sure-hit lethal blow, allowing him to briefly survive a domain collapse before the remaining attacks deplete his counter.
