# Minor Cursed Techniques — Summons & Entities Specification

## 1. Entities & Cursed Tools
- **G Warstaff Cursed Tool Entity (`crb:g_warstaff`)**:
  - Distinctive polearm weapon featuring an oversized bronze/steel G-pen nib capable of holding ink reserves.
- **Hand Sword Cursed Tool (`crb:hand_sword`)**:
  - Haruta Shigemo's flexible rapier whose pommel is shaped like a human hand that grips the wielder's wrist, giving it unpredictable angles and reach.
- **Manga Future Panel Entity (`crb:manga_future_panel`)**:
  - Lightweight billboard entity rendered via Veil shader in the client's local worldspace, tracking the target's relative position.
