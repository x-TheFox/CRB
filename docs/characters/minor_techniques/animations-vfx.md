# Minor Cursed Techniques — Animations & VFX Specification

## 1. Animation Manifest
- **Player Animation Library (Java)**:
  - `haruta_cowardly_dodge`: Exaggerated stumble backward tripping over own feet to narrowly dodge a lethal blade.
  - `charles_gpen_thrust`: Precise fencing lunge with the G-warstaff nib.
  - `painkiller_infusion`: Palm pressed against chest or ally's shoulder with soft teal healing pulse.
  - `sight_glare`: Menacing forward stare with purple ocular flare.

## 2. VFX Particle Architecture
- **Visuals**:
  - `crb:miracle_mark`: Purple triangle glyphs floating under Haruta's eye models.
  - `crb:manga_future_panel`: Monochrome halftone manga comic strip projected in 3D space above the target showing their upcoming animation frame.
  - `crb:anesthetic_mist`: Pale cyan vapor enveloping the player.
  - `crb:ocular_beam`: Faint purple focus lines converging between caster's and victim's eyes.
