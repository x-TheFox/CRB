# Kinetic & Curse Absorption — Summons & Entities Specification

## 1. Projectiles & Entities
- **Absorption Plasma Beam Entity (`crb:absorption_beam`)**:
  - High-intensity continuous linear raycast entity.
- **Supernova Core Entity (`crb:supernova_core`)**:
  - Floating incandescent orb spawned above the user during `absorption8` startup.
  - Pulls nearby loose items and particles toward itself via gravitational suction before bursting.
- **Boss / Mini-Boss Variant (`crb:absorption_sorcerer`)**:
  - Advanced SmartBrainLib humanoid sorcerer that prioritizes defensive guarding when under attack, building up charge to unleash retaliatory beams.
