# Toge Inumaki — Domain Expansion: Resonant Chamber (共鳴の領域)

## 1. Domain Status & Lore Adaptation
- **Canon Status**: Inumaki never unlocked an innate domain expansion in canon.
- **JJA Adaptation**: JJA included a custom domain adaptation: `speech_domain`, `resonant_chamber`, `speech_domain_start`.
- **CRB Implementation**: Retained for full JJA parity with optional YACL config toggle.

## 2. Domain Mechanics & Specifications
- **Barrier Type**: Enclosed 55-block spherical domain with acoustic egg-crate soundproofing foam patterns and undulating soundwave oscilloscope walls.
- **Sure-Hit Effect (Echo Chamber)**:
  - **Acoustic Omnipresence**: Inside the chamber, acoustic reflection is amplified infinitely.
  - Any verbal command spoken by Inumaki rebounds off every wall simultaneously, striking all enemy entities from all 360-degree angles.
  - **Zero Distance Attenuation**: Commands cannot be dodged or blocked with simple ear covering.
  - Inumaki suffers zero throat strain recoil while speaking inside his own domain because the ambient sonic resonance sustains the cursed syllables.
