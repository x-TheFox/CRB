# Megumi Fushiguro — JJA Parity Checklist

This checklist defines the complete, itemized parity contract between the JJA Bedrock addon and the CRB Java Edition mod for Megumi Fushiguro. Every item must be verified green before Phase 4 completion for this character.

## 1. Core Mechanics & Passives
- [ ] **Shadow Storage**: Ability to stash weapons and cursed tools inside player's shadow.
- [ ] **Shadow Submersion**: Can melt into flat shadow surfaces to evade attacks.
- [ ] **Zenin Heritage**: Compatible with Zenin clan traits and armaments.

- [ ] **Toad (`ds:shikigami2`)**: Tongue reel and grapple mechanics.
- [ ] **Divine Dogs (`ds:shikigami3`)**: Pack hound tracking and Totality transformation upon casualty.
- [ ] **Nue (`ds:shikigami4`)**: Flight strafe, electric wing shocks (`nue_bolt.mcfunction`).
- [ ] **Great Serpent (`ds:shikigami5`)**: Subterranean launch strike.

- [ ] **Round Deer (`ds:shikigami8`)**: Positive energy RCT healing aura.
- [ ] **Merged Beast Agito (`ds:shikigami11`)**: Four-way chimera fusion summon.
