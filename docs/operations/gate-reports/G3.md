## 2. Architectural Decision Records (ADRs) Delivered
Five foundational ADRs have been authored and accepted into the project repository:
1. `docs/architecture/ADR-001-ability-engine.md`: State-machine ability framework with server-authoritative casting, input queuing, and combo chaining.
2. `docs/architecture/ADR-002-cursed-energy-and-progression.md`: Type-safe `CursedEnergyData` attachment using NeoForge 1.21.1 attachments, grade progression from Grade 4 to Special Grade, trait multipliers (Six Eyes, Heavenly Restriction), and burnout recovery.
3. `docs/architecture/ADR-003-payload-networking.md`: Multiplayer-safe networking using immutable `CustomPacketPayload` records and `PayloadRegistrar`.
4. `docs/architecture/ADR-004-camera-director.md`: Cinematic camera choreography integrating Free Camera API 2.1.1, cubic bezier easing, and MAPPA-style impact frames.
5. `docs/architecture/ADR-005-domain-expansion-and-clashing.md`: Mathematical domain barrier engine supporting 66-block spherical closed barriers, 200-block open barriers (Malevolent Shrine), non-lethal courtrooms, and refinement rating clash tug-of-war.

## 3. Vertical Slice Deliverables & Codebase
The following production-grade Java 21 classes have been engineered, compiled, and packaged:
- `com.crb.CursedRealityBoundless`: Main mod entrypoint initializing registries and setup events.
- `com.crb.core.init.ModRegistries`: Central deferred registers for items, creative tab, and `AttachmentType<CursedEnergyData>`.
- `com.crb.core.cursedenergy.CursedEnergyData`: Persistent NBT-serializable player capability tracking CE, max CE, traits, clans, grades, and burnout.
- `com.crb.core.cursedenergy.SorcererGrade`: Grade progression enum (Grade 4 through Special Grade).
- `com.crb.core.cursedenergy.Clan`: Gojo, Zenin, Kamo, Inumaki, Itadori lineage mappings.
- `com.crb.core.cursedenergy.Trait`: Six Eyes (0.001x cost efficiency), Heavenly Restriction (0 CE lock), Electrified CE, Rough CE.
- `com.crb.core.ability.Ability` & `AbilityCategory`: Base stateful ability contract.
- `com.crb.content.characters.gojo.LapseBlueAbility`: Authoritative spatial attraction vector physics and crushing damage.
- `com.crb.content.characters.gojo.HollowPurpleAbility`: Multi-block marching imaginary mass raycast with true spatial erasure bypassing conventional armor.
- `src/main/resources/assets/crb/lang/en_us.json`: Localization strings for abilities, tabs, and grades.
