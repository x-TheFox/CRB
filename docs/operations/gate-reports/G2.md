2. **GeckoLib (4.9.3)** — `geckolib-neoforge-1.21.1-4.9.3.jar`

   - High-fidelity first/third-person player combat animations without breaking armor rendering or replacing the player model.
4. **Veil (4.5.2)** — `veil-neoforge-1.21.1-4.5.2.jar`
   - Premier post-processing engine for emissive bloom, screen refraction passes (Infinity), domain barrier domes, and volumetric particle ribbons.
5. **Yet Another Config Lib / YACL (3.8.2)** — `yet_another_config_lib_v3-3.8.2+1.21.1-neoforge.jar`
   - Modern accessible config GUI for particle scaling, camera shake, keybindings, and canon purist mode.
6. **SmartBrainLib (1.16.11)** — `SmartBrainLib-neoforge-1.21.1-1.16.11.jar`
