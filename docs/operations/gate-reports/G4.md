## 3. Mathematical Domain Expansion Engine
- **Barrier Types (`BarrierType`)**:
  - `CLOSED_SPHERE`: Standard enclosed spherical domain (66-block diameter, physical boundary).
  - `OPEN_BARRIER`: Divine painting on thin air (200-block radius, no physical shell, attacks ambient structures).
  - `NON_LETHAL_COURTROOM`: Violence-prohibited domain space for legal judgment.
  - `POCKET_DIMENSION`: Sub-dimensional space transition.
- **Clashing Mechanics (`DomainManager`)**:
  - Real-time overlapping bounding sphere detection.
  - Refinement rating differential evaluation:
    $$\Delta R = R_{\text{new}} - R_{\text{existing}}$$
    - $|\Delta R| > 50.0$: The weaker domain's barrier immediately shatters.
    - $|\Delta R| \le 50.0$: Both domains enter mutual interference; sure-hits are cancelled inside the overlap zone.
  - Server tick integration: Continuous lifecycle updates via `LevelTickEvent.Post`, applying 600 ticks (30s) of Cursed Technique Burnout to casters upon barrier dissolution.

## 4. Admin & Debug Brigadier Commands (`/jjk`)
- `/jjk energy set <amount>`: Set exact current Cursed Energy pool.
- `/jjk grade set <gradeName>`: Advance sorcerer grade (`GRADE_4` through `SPECIAL_GRADE`).
- `/jjk trait set <traitName>`: Assign traits (`SIX_EYES`, `HEAVENLY_RESTRICTION`, etc.).
- `/jjk clan set <clanName>`: Assign bloodline lineage (`GOJO`, `ZENIN`, `KAMO`, etc.).
- `/jjk burnout clear | apply <ticks>`: Control technique burnout state.
- `/jjk domain clear`: Instantly dissolve all active domains in the world.
- `/jjk ability list`: List all 31 registered abilities with CE costs.
- `/jjk ability cast <ability_id>`: Cast any ability server-side with full cost and validation checks.
